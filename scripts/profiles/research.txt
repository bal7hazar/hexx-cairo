# rule (deny wins over allow); `@name` includes the profile `name`; `#` starts a comment.

# worktree only; anything outside it, and anything not listed here, is refused.

# Secrets. The user-level settings of the machine define credentials (the registry token, the
# Sepolia account) for every claude process. The launcher empties them in every agent through
# its `--settings` override (measured on 2026-09-28 from a clean environment). These rules stop
# the typed forms of reading them back; code an agent runs (python3, a script) can still read
