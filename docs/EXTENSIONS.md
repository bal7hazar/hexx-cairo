# Extensions

Generated by `python3 scripts/api_parity.py --extensions`. What Cairo and the network require beyond `hexx` (COMMON.md §7): boards as bitmaps in one felt, generation, floods, assembly. Outside the parity table (`docs/API_PARITY.md`), listed here by module so it stays inventoried (plan §4.2).
