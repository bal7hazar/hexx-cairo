# [GPT-6-Astra] Audit — LIB-03 — design (pass 2)

## Verdict

FAIL

The revision resolves many pass-1 findings and incorporates Cairo 2.19 and reduced N-9 correctly. Remaining failures include carry propagation in N-1, field overflow in N-2, insufficient shared tables, an unsafe edge-target path in `approach`, and understated gas targets.

## Coverage

Reviewed the revised plan, all 20 pass-1 findings, the updated source-version record, ADR-0007, reduced N-9, the relevant binding game decisions, and the upstream implementations used by the corrected algorithms. Reviewed D-1 through D-30 and the added D-31.

Read-only, in-memory checks included:

- N-1 scalar-versus-plane comparisons for both parities and multiple dimensions. These exposed finding 21. Replacing the overlapping plane additions with OR passed 1,000 sampled comparisons; this is diagnostic evidence, not a shipped implementation.
- N-2 scalar global-coordinate comparisons on all four sides and both parities. Required chunk dimensions passed the exercised cases; larger advertised dimensions exposed finding 22.
- N-3: all **225 offsets / 900 pieces** again partitioned the window correctly using the mathematically required rectangles. The declared array endpoints remain defective.
- N-5: **20,706** ordered pairs within distance six passed table placement and off-board detection; symmetry held across all **57,600** ordered window pairs. Edge-target `approach` failed separately.
- N-6: **1,920** centre/radius cases passed pre-shift clipping using complete 16-row bands. Those checks do not validate the insufficient arrays declared in the plan.
- N-8: **1,000** frozen-occupancy selection cases passed independent scalar selection checks. Rechecked the winding corridor’s layer count and the effect of additional frozen walkers.
- Recomputed operation sums, checked cited measured figures, and verified all five relative Markdown links.

The proposed library has **no Dojo dependency**. Remaining Dojo mentions describe superseded architecture, removed metadata or upstream repository provenance. Cairo 2.19, retained `BoundedInt`, native consumers and snforge-only testing agree with ADR-0007.

**N-9 has a demonstrable planned exit criterion:** Plan:1054 requires two independent consumers to resolve and build against the published package, plus a registry dependency check; M1-N9 owns the checks. This appropriately tests the published artifact rather than trusting the source manifest. It has not yet been executed.

AC-1, AC-3, AC-6, AC-8 and AC-9 remain structurally satisfied. AC-2 needs final inventory consistency; AC-4, AC-5 and AC-7 remain blocked by the correctness, budgeting and implementation-readiness findings above.

No files were written. No Cairo compilation, gas measurement, class-size measurement, registry publication or live dependency-resolution test was performed. Those require implementation or external state; this report audits the design and its stated evidence.
